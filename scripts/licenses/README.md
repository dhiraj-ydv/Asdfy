Standard license texts from the SPDX License List
([spdx/license-list-data](https://github.com/spdx/license-list-data) v3.29.0,
`text/`), named by SPDX identifier. `scripts/third-party-notices.mjs` uses them for
packages published without a license file, filling the copyright line from the
package's authors. When a build stops because a template is missing, add the
identifier's file from the same source.
